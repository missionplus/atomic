# Fake for `<service-name>`

A dramatically cut-down stand-in for `<service-name>`. Use this to run
integration tests against this service without standing up the real thing.

This fake was generated by the **Atomic** Claude Code plugin (`generate-fake`
skill). To keep it in sync with the real service after the application
changes, run the `update-fake` skill.

## What this is

- A small Python (FastAPI) / Node (Fastify) HTTP server.
- Optionally: in-process queue consumers/producers, an in-memory store, and a
  SQLite stand-in for any required tables.
- Runs in one container, on a laptop.
- Returns canned responses for most endpoints; simple deterministic transforms
  for endpoints where the consumer test cares about input/output relationship;
  a tiny in-memory store for the small set of endpoints that need read-after-write.

## What this is NOT

- It is **not** a complete simulation of `<service-name>`. Many edge cases,
  validation rules, and business logic are intentionally absent.
- It is **not** for performance testing.
- It is **not** for security testing — the fake accepts any well-formed auth.

## Run it

```bash
docker compose -f docker-compose.fake.yaml up
# OR
pip install -r requirements.txt && python app.py
# OR
npm install && npm start
```

The fake binds to `0.0.0.0:8000` by default. Override with `FAKE_PORT`.

## Pointing your application at the fake

See `consumer-config.example.env`. The short version:

```bash
ORDERS_SERVICE_URL=http://localhost:8000
ORDERS_SERVICE_TOKEN=fake-token
```

## Admin endpoints

- `POST /__reset` — wipe all in-memory state. Call between test cases.

## Keeping the fake in sync

Run the `update-fake` skill on this folder after the real application changes.
It will:

1. Re-read `fake.manifest.yaml`.
2. Compare it against the current real-application source.
3. Propose patches for changes (additive, breaking, cosmetic).
4. After your approval, apply patches and refresh the manifest.

Do not hand-edit `fake.manifest.yaml` unless you know what you're doing — it's
how `update-fake` knows what the fake currently covers.
